Discovery enrollment showcase

Manual listening test for the next-phase flow: blind separation finds the speakers in a conversation, you pick one, and a live extraction model keeps only that voice. Controlled clean LibriSpeech conversations with 4–6 speakers; offline research models, not real-time or phone timing.

Each clip is peak-normalized for listening, so compare which voices remain, clarity, and leakage, not loudness. SepFormer works at 8 kHz, so its outputs sound band-limited. Thresholds were tuned on dev mixtures; test mixtures use disjoint speakers.
